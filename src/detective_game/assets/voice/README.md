# Озвучка

Голос рассказчика для катсцен. Файлы читаются из этой папки в таком порядке:
`.ogg` → `.wav` → `.mp3` (первый найденный).

## Имена файлов

`cutscene_<дело>_<номер кадра>.ogg`, номер кадра — с единицы:

| Файл | Когда звучит |
| --- | --- |
| `cutscene_tutorial_1.ogg` … `_3` | учебное дело «Пропавший кот» |
| `cutscene_missing_chess_1.ogg` … `_3` | «Загадочное похищение» |
| `cutscene_bank_heist_1.ogg` … `_3` | «Тень ячейки №314» |

Если файла нет — игра молчит, но **субтитры и тайминг остаются**: катсцена
работает как обычно. Если файл есть, кадр держится на экране не меньше
длительности записи (`voice_length()` + 0.9 с), чтобы голос не обрывался.

## Как заменить голос

1. Запишите текст подписи кадра (он же субтитр) — `case_cutscenes.py`, поле `caption`.
2. Положите файл с нужным именем в эту папку. Формат: моно, 44.1 кГц, ogg или mp3.
3. Перезапустите игру. В настройках есть переключатель **«Озвучка»**: выключить
   голос, оставив субтитры, можно там же.

Текст озвучки намеренно совпадает с подписью кадра: то, что слышно, видно и на
экране — так катсцену можно смотреть без звука.

Остальные звуки (музыка и эффекты) генерируются кодом в `synth.py` и в этой
папке не лежат.
