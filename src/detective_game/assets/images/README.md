# Assets — изображения

Часть экранов уже рисуется по-настоящему, часть — процедурно (цветовые
аватары, градиенты).

## Что есть

- `icon.ico` / `icon.png` — иконка exe (нуар-шляпа).
- `detective_01..06.png` — портреты детективов (игрок выбирает в
  «Кастомизации»); используются в меню, диалогах и списках.
- `maps/blackville.jpg`, `maps/northport.jpg`, `maps/downtown.jpg` —
  карты-картинки городов/районов (16:10). Привязываются к делу полем
  `"map"` в JSON дела (см. `data.DEFAULT_CASE_MAP` и `data.case_map()`).
- `locations/*.jpg` — иллюстрации локаций по **типу** места (`hub`, `bar`,
  `police`, `crime`, `mansion`, `public`, `apartment`, …). Соответствие
  «тип → файл и цветная вуаль» — `ui/location_art.py`.
- `tutorial/` — картинки для главы «Туториал».

Все картинки грузятся через `ui/artwork.py`: `cover_image()` обрезает по
размеру панели, затемняет (`dim`) и подкрашивает (`tint`), `blit_rounded_image()`
выводит со скруглёнными углами. Если файла нет — код рисует запасной фон,
поэтому удаление картинки не ломает игру.

## Как добавить свою картинку

1. Положи файл в `src/detective_game/assets/images/` (желательно JPEG
   1280×720, до ~300 КБ).
2. Для локации — допиши строку в `ui/location_art.LOCATION_ART`
   (`тип: ("locations/имя.jpg", вуаль_или_None)`), либо укажи поле
   `"image"` прямо у локации в JSON дела.
3. Для карты дела — поле `"map": "maps/имя.jpg"` в JSON дела.
4. `tools/build.ps1` уже копирует всю папку `assets` (`--add-data`), править
   сборку не нужно.
