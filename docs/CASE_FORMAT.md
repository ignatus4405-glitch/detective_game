# CASE_FORMAT — формат дел (кейсов)

Дело — JSON-файл в `src/detective_game/cases/<id>.json` (или встроенный dict в `data.py:BUILTIN_CASES`).

## Скелет

```json
{
  "id": "my_case",
  "title": "Короткое название",
  "subtitle": "Подзаголовок (1 строка)",
  "difficulty": "★★☆",
  "duration": "60–90 мин",
  "price": "990 ₽",
  "description": "Кратко для карточки выбора (2 предложения)",
  "intro": "Завязка — показывается при старте дела (3-4 предложения)",
  "recommended_time": 90,
  "locations": [...],
  "clues": [...],
  "characters": [...],
  "suspects": [...],
  "endings": {...}
}
```

## Сложность дела (`advanced`)

Большие дела включают «взрослые» правила одним флагом:

```json
{
  "id": "my_case",
  "advanced": true,
  "deadline_days": 3
}
```

| Поле | Значение |
| --- | --- |
| `advanced` | `true` — включаются срок, экспертиза, таймер реплики, патруль, противоречия, суд и анонимные звонки. Без флага (как в туториале) всё работает по-старому |
| `deadline_days` | срок дела в днях (по умолчанию 3) |
| `deadline_minutes` | точный срок в игровых минутах, если нужно иначе |

## Локации (`locations`)

```json
{
  "id": "park",
  "name": "Парк Роузвуд",
  "type": "crime",
  "x": 300, "y": 200,
  "district": "Север",
  "desc": "Описание для экрана локации",
  "initial": true
}
```

- `type`: `hub`/`police`/`crime`/`bar`/`apartment`/`bank`/`vault`/`public`/`shop`/`warehouse`/`port`/`mansion`/`office` — влияет на цвет пина
- `x,y`: координаты 0..1280,0..720 (как на карте)
- `district`: для легенды (Центр, Порт, Запад, Север, Холмы, Юг, Восток)
- `initial`: если `true` — доступна с начала, иначе открывается когда собрана улика с `leads_to` содержащим её `id`
- `hours` (необязательно): `[открытие, закрытие]` в часах, например `[18, 2]`
  для бара. Если не задано — берётся по типу локации: бар 18–02, банк 9–17,
  участок 8–20, школа 8–15, особняк 10–18, магазин 10–20, квартира 8–22,
  публичные места 8–21, офис/порт/склад/место преступления — круглосуточно.
  Дело начинается в 9:00, кнопка «ЖДАТЬ» на карте проматывает время до
  ближайшего открытия. Офис открыт всегда, тупика нет.

## Улики (`clues`)

```json
{
  "id": "clue_camera",
  "title": "Камера Ланского",
  "desc": "Длинное описание улики",
  "location": "park",
  "importance": "high",
  "leads_to": ["photo_lab"]
}
```

- `location`: id локации где лежит
- `importance`: `high`/`medium` — цвет индикатора
- `leads_to`: массив локаций которые откроются после сбора
- `hidden` (необязательно): `true` — улику не видно в списке локации, пока
  игрок не найдёт её при **обыске** (кнопка «ОБЫСКАТЬ» на иллюстрации).
  Точки обыска детерминированы, а координаты можно задать полем `spot`.
- `spot` (необязательно): `[x, y]` — где именно лежит улика при обыске
  (доли от размера картинки, 0..1). Без него позиция считается по сиду дела.
- `reliability` (необязательно): достоверность улики в больших делах:
  `solid` (по умолчанию — суд принимает сразу), `hearsay` (слух: нужна
  экспертиза, иначе суд не считает), `planted` (подброшена: экспертиза
  изымает её из блокнота и снижает репутацию). Лаборатория стоит $50,
  45 минут и репутацию 2+.

### Замок на улике (`puzzle`)

Необязательное поле: если оно есть, улика не берётся одним кликом — сначала
нужно открыть замок. Кнопка на локации меняется с «ИЗУЧИТЬ» на «ВЗЛОМАТЬ».

```json
{
  "id": "clue_log",
  "title": "Журнал сигнализации",
  "puzzle": {
    "type": "safe",
    "difficulty": 1,
    "title": "ПАНЕЛЬ СИГНАЛИЗАЦИИ",
    "code": "0214",
    "hint": "В журнале записано: отключение началось в 02:14.",
    "reward": "Журнал дежурства — в блокноте",
    "attempts": 6
  }
}
```

| Поле | Значение |
| --- | --- |
| `type` | `safe` (кодовый замок), `lockpick` (отмычки), `wires` (какой провод резать), `sequence` (запомнить и повторить), `alibi` (сетка «кто где был»), `develop` (проявка плёнки: три ползунка), `align` (совмещение отпечатков или голоса) |
| `difficulty` | 1–3: сложность и число попыток |
| `title` | заголовок экрана; по умолчанию — название типа |
| `hint` | подсказка в правом верхнем углу; **обязательно** для играбельной улики |
| `reward` | что получит игрок («Улика попадёт в блокнот» по умолчанию) |
| `attempts` | переопределить число попыток (`safe` 6, `lockpick` 3, `wires` 2, `sequence` 2) |
| `code` | только для `safe`: 3–4 цифры строкой или массивом; если нет — код случайный |
| `people`, `places` | только для `alibi`: списки людей и мест (места — словарями `{"name", "phrase"}`); по умолчанию 3×3 |
| `targets`, `start` | только для `develop`: цели ползунков (22..78) и стартовые значения |
| `mode` | только для `align`: `fingerprint` (по умолчанию) или `voice` (сопоставление голоса) |

Провал не блокирует дело: попытка стоит 15 минут игрового времени, к замку
можно вернуться. Победа начисляет улику, её `leads_to` и +10 минут, как при
обычном сборе. Готовые примеры — в `data.py` (по 3 головоломки на дело).

## Персонажи (`characters`)

```json
{
  "id": "elena",
  "name": "Елена Морозова",
  "role": "Мать Артёма",
  "location": "apartment_morozov",
  "bio": "Краткая био (1 предложение)",
  "portrait_color": [120,80,80],
  "dialogue": [
    {"q": "Вопрос детектива", "a": "Ответ персонажа"}
  ]
}
```

- `portrait_color`: RGB для заглушки-аватара
- `schedule` (необязательно): `[от, до]` в часах — когда персонаж на месте.
  Например, бармен `[18, 2]` (через полночь), учитель `[8, 15]`. Вне часов
  кнопка «ДОПРОСИТЬ» гаснет, а на карточке написано, когда он вернётся.
- `dialogue`: массив реплик, показываются по очереди при допросе

### Тема допроса с выбором, ложью и доской

```json
{
  "prompt": "В прошлый четверг во дворе ждал мужчина. В плаще.",
  "requires": {"board": "roma_sus"},
  "lie": {
    "clue": "clue_camera",
    "claim": "Я не приходила в парк в тот вечер.",
    "reply": "…Я проходила мимо. И видела, как Ланский снимал.",
    "trust": 1,
    "time": 5,
    "bonus_clue": "clue_photos"
  },
  "options": [
    {"text": "Что вы видели?", "reply": "…", "trust": 1, "tone": "мягко", "clue": "clue_diary", "time": 10}
  ]
}
```

| Поле | Значение |
| --- | --- |
| `requires` | когда тема открывается. `{"board": true}` — нужна любая собранная версия на доске, `{"board": "<suspect_id>"}` — версия по этому подозреваемому, `{"deduction": "<id>"}` — найденное противоречие показаний |
| `lie.clue` | улика, которая противоречит словам; без неё кнопка «УЛИЧИТЬ ВО ЛЖИ» неактивна |
| `lie.reply` | что персонаж скажет, когда его поймали |
| `lie.trust` / `lie.time` / `lie.bonus_clue` | награда: доверие (по умолчанию +2), минуты (5), дополнительная улика |

## Подозреваемые (`suspects`)

```json
{
  "id": "finch",
  "name": "Эдвард Финч",
  "motive": "Короткий мотив",
  "evidence": ["clue_camera","clue_ticket"],
  "is_culprit": true
}
```

- `evidence`: список id улик, которые указывают на него (для подсказки в досье)
- `is_culprit`: `true` только у одного — правильный ответ

## Хронология (`timeline`)

```json
"timeline": [
  {"id": "t1", "time": "21:12", "text": "Барсик сидит на подоконнике"},
  {"id": "t2", "time": "21:20", "text": "Кто-то отворачивает защёлку"}
]
```

Порядок событий в списке — правильный. Перед обвинением игрок расставляет
карточки; одна проверка стоит 10 минут, победа даёт +2 репутации и повышает
ранг финала на ступень. Если поля нет — берётся встроенный таймлайн дела
(`timeline.py`), а если и его нет — экран не предлагается.

## Слежка (`surveillance`)

```json
"surveillance": {
  "title": "Слежка за Финчем",
  "target": "Эдвард Финч",
  "place": "Порт Блэквила",
  "requires_clue": "clue_bar_testimony",
  "seconds": 24,
  "band": [0.26, 0.68],
  "reveal": "clue_fabric",
  "reputation": 1,
  "money": 120,
  "description": "Бармен сказал, что Финч каждый вечер уходит в порт…",
  "routes": [
    {"id": "river", "title": "Вдоль реки", "minutes": 15, "note": "…", "correct": true},
    {"id": "tram", "title": "На трамвае", "minutes": 25, "note": "…"}
  ]
}
```

| Поле | Значение |
| --- | --- |
| `requires_clue` | без этой улики кнопка «СЛЕЖКА» неактивна |
| `band` | зелёная зона дистанции (доли 0..1); верный маршрут её расширяет, крюк — сужает |
| `reveal` | какую улику открывает удачная слежка |
| `routes` | варианты маршрута до начала; ровно один с `"correct": true` |
| `money` / `reputation` | награда за успех |

Управление: **→/D** — догонять, **←/A** — отставать, ничего — идти ровно.
Слишком близко растёт «подозрение», слишком далеко — «риск потерять».

## Противоречия показаний (`contradictions`)

```json
"contradictions": [
  {
    "id": "thursday_tea",
    "a": "elena:9",
    "b": "roma:8",
    "title": "Чай в четверг",
    "text": "Елена говорит, что была одна, Роман — что пил у неё чай.",
    "reputation": 1
  }
]
```

- `a`/`b` — ключи реплик `"персонаж:номер_темы"`; сравнивать можно только те,
  что игрок уже открыл в допросах;
- верная пара даёт вывод (`state.deductions`), репутацию и открывает темы
  с `requires: {"deduction": "thursday_tea"}`;
- неверная пара стоит 2 минуты и −1 доверие собеседникам;
- новые темы добавляйте в конец диалога, чтобы не сдвигать индексы.

## Суд (`trial`)

```json
"trial": {
  "motives": [{"id": "collection", "text": "Одержимость"}],
  "methods": [{"id": "frame", "text": "Спрятал ребёнка и подставил соседа"}],
  "answers": {"finch": {"motive": "collection", "method": "frame"}}
}
```

На экране обвинения в больших делах игрок выбирает мотив и способ. Оба верных
ответа поднимают ранг финала на ступень, оба неверных — опускают, один — без
изменений. Без `trial` суд спрашивает только «кто».

## Концовки (`endings`)

Ключ = `id` подозреваемого:

```json
{
  "finch": {"success": true, "title": "Правосудие", "text": "Длинный текст финала (3-5 предложений)", "rank": "S"},
  "roma_sus": {"success": false, "title": "Ошибка", "text": "...", "rank": "D"}
}
```

- `rank`: S/A/B/C/D/F — показывается на экране финала

## Пример готового файла

Сохрани как `src/detective_game/cases/tutorial.json` и перезапусти игру — дело появится.

См. встроенные примеры: `src/detective_game/data.py`.

## Лимиты (MVP)

- До 20 локаций, 15 улик, 8 персонажей, 5 подозреваемых — больше не тестировалось
- Координаты `x,y` не должны налезать друг на друга (<60px дистанция)
- ID должны быть уникальны и без пробелов
