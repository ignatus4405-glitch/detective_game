# Как играть — «Школа детектива»

![Анимированный обзор туториала](tutorial.gif)

В игре обучение встроено: **Меню → «ТУТОРИАЛ»** (или клавиша **F1**). Экран целиком
интерактивный — можно потыкать карту, раскрыть улики, переключить вкладки блокнота,
выбрать ответ в допросе и посмотреть «видео-обзор» полного цикла расследования.

![Интро](01_intro.png)

## 1. Как играть: одно дело — три шага

Цель — найти виновного и предъявить обвинение. Расследование идёт по кругу:

1. **Карта** — ходите по локациям, тратя игровое время.
2. **Улики** — находите и читайте: важные (★) открывают новые места.
3. **Обвинение** — когда собрано 3+ улики, выбираете, кто виновен.

## 2. Карта города

![Карта](02_map.png)

- Каждый **пин** — локация. Клик по пину = переход, ровно как в игре.
- **Жёлтое кольцо** — где вы сейчас; **✓** — где уже были.
- Серые пины закрыты, пока не найдёте нужную улику.
- Кнопки в шапке: **БЛОКНОТ**, **ДОСЬЕ**, **ОБВИНИТЬ** (доступна с 3 улик).

> В этой версии починен клик по пинам: раньше отрисовка масштабировала
> координаты внутрь панели карты, а проверка клика брала исходные координаты дела —
> на 1280×720 промах достигал 100+ пикселей.

## 3. Улики

![Улики](03_clues.png)

Нашли — прочитали — связали:

- **★ важная** улика почти всегда открывает новую локацию;
- **☆ обычная** добавляет деталь к показаниям;
- у каждой улики есть «**Ведёт в**» — куда идти дальше;
- в игре всё это лежит в журнале справа и в блокноте.

## 4. Блокнот

![Блокнот: улики](04_notebook.png)
![Блокнот: подозреваемые](05_notebook_suspects.png)
![Блокнот: карта](04b_notebook_map.png)

Три вкладки:

| Вкладка | Что внутри |
| --- | --- |
| **Улики** | все находки, ★ важные, ☆ второстепенные |
| **Подозреваемые** | мотив, алиби и связи с уликами |
| **Карта** | карта города с пинами (те же локации, что на экране карты) и заметки |

## 5. Допрос

![Допрос](06_dialogue.png)
![Выбор реплики и последствия](06b_dialogue_choice.png)

Персонаж говорит первым — это задаёт тему. Дальше вы **выбираете, что сказать**:
2–3 варианта реплики, у каждого свой ответ и свои последствия.

| Метка у реплики | Что делает |
| --- | --- |
| **мягко** | доверие +1: персонаж раскрывается, открывается бонус |
| **по делу** | доверия не меняет, но иногда сразу даёт улику |
| **жёстко** | доверие −1: допрос идёт быстрее, но бонуса не будет |

- варианты выбираются **кликом или клавишами 1–3**, дальше — пробел/Enter;
- выбранную реплику нельзя переиграть: она сохраняется в сейве;
- справа вверху — **шкала доверия** (5 делений, красные — уже минус);
- при достаточном доверии в конце допроса персонаж выдаёт **бонус** —
  признание или улику, которой нет в локации;
- старые линейные вопросы остались: они идут после тем с выбором.

Сверяйте даты: кто путается — врёт.

## 6. Обвинение

![Обвинение](07_accuse.png)
![Вердикт](08_accuse_verdict.png)

- открывается при **3+ уликах**;
- выбираете подозреваемого → «ПРЕДЪЯВИТЬ ОБВИНЕНИЕ»;
- верно — дело закрыто, ошибка — экран провала (игру можно начать заново);
- в туториале можно нажать «ПОПРОБОВАТЬ СНОВА» и посмотреть оба исхода.

## 7. Видео-обзор

![Видео: карта](09_demo_map.png)
![Видео: улика](10_demo_clue.png)
![Видео: блокнот](11_demo_notebook.png)

«Видео» — это анимированный проход по игре: плеер, таймлайн, пауза, перемотка
и чипы сцен. Кликается всё:

| Элемент | Действие |
| --- | --- |
| ▶ / ❚❚ | пуск и пауза |
| **⟲ СНАЧАЛА** | сброс на 0:00 |
| таймлайн | перемотка в любое место |
| чип «1. Карта…» | прыжок к сцене |
| клик по кадру | пауза |
| **Пробел** | пауза |

## Управление туториалом

| Клавиша / кнопка | Действие |
| --- | --- |
| **F1** | открыть «Школу детектива» из меню/настроек |
| **←** / **→** | предыдущая / следующая глава |
| **Esc** | выход в меню |
| Пробел | пауза «видео» |
